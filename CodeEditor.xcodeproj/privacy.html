Privacy Policy

Last Updated: April 11, 2026

🔒 Privacy First Commitment

Clarity Code collects ZERO data. Your code stays on your Mac. Period.

We don't track you, we don't analyze your usage, and we don't collect any information about you or your files. This privacy policy explains exactly what that means.

1. Overview

Clarity Code ("we," "our," or "the App") is a native macOS code editor developed by Sonoma Enterprises. This Privacy Policy describes how we handle information when you use our application.

The short version: We don't collect, store, transmit, or process any of your data. Ever.

2. Information We Do NOT Collect

Clarity Code is designed with privacy as a core principle. We do not collect:

  • Personal Information: No names, email addresses, or contact information
  • Usage Data: No analytics about how you use the app
  • File Contents: We never see, access, or transmit your code or documents
  • File Names or Paths: We don't track what files you open or edit
  • Crash Reports: No automatic crash reporting or diagnostics
  • Device Information: No data about your Mac, OS version, or hardware
  • Behavioral Data: No tracking of features used or time spent in the app
  • IP Addresses: No network requests that would expose your IP address
  • Cookies or Tracking: No cookies, pixels, or tracking technologies
  • Location Data: No access to or collection of location information

Why zero data collection?

Your code is your intellectual property, your trade secrets, and your creative work. We believe that code editors should be tools that work for you, not surveillance systems. Clarity Code runs entirely on your Mac with no "phone home" functionality.

3. How Your Data Stays Private

3.1 Local-Only Processing

All code editing, syntax highlighting, language detection, and file operations happen entirely on your Mac. Your files never leave your device.

3.2 No Internet Connection Required

Clarity Code works completely offline. The app does not require or make any internet connections except:

  • Initial app download from the Mac App Store
  • App updates from the Mac App Store
  • In-app purchase transactions (handled securely by Apple's StoreKit)

3.3 No Third-Party Services

We do not integrate with or send data to:

  • Analytics services (e.g., Google Analytics, Mixpanel)
  • Crash reporting tools (e.g., Crashlytics, Sentry)
  • Advertising networks
  • Cloud storage providers (unless you explicitly choose to save files there)
  • Any other third-party services

3.4 App Sandbox

Clarity Code runs in the macOS App Sandbox, which restricts the app's access to:

  • Only files you explicitly open or save
  • No access to other apps' data
  • No network access except for App Store transactions
  • No access to your camera, microphone, or location

4. In-App Purchases

Clarity Code offers a one-time in-app purchase to unlock premium features. Purchase transactions are handled entirely by Apple through StoreKit.

What Apple Collects for Purchases:

  • Your Apple ID and payment information (managed by Apple, not us)
  • Purchase history (stored in your Apple ID, not accessible to us)
  • Receipt validation data (Apple verifies purchases, we only check if premium is unlocked)

We do not see, store, or have access to:

  • Your Apple ID
  • Your payment information
  • Your purchase history
  • Any personally identifiable information from purchases

For information about how Apple handles purchase data, please see: Apple's Privacy Policy

5. Files and Documents

5.1 File Storage

All files you create or edit in Clarity Code are stored:

  • On your local Mac storage (where you choose to save them)
  • Never uploaded to any server or cloud service by the app
  • Accessible only to you through standard macOS file permissions

5.2 iCloud and Cloud Storage

If you choose to save files to iCloud Drive or other cloud storage:

  • This is your explicit choice through macOS file dialogs
  • The app simply saves to the location you select
  • Cloud syncing is handled by macOS and your cloud provider
  • We have no access to or control over cloud storage

5.3 Auto-Save and Versions

macOS may automatically save versions of your documents. This is a system-level feature:

  • Managed by macOS, not our app
  • Stored locally on your Mac
  • You can disable this in System Settings if desired

6. Permissions

Clarity Code requests only essential permissions:

Required Permissions:

  • File Access: To open and save files you select
  • Print Access: To print documents when you choose to print

NOT Requested:

  • Camera
  • Microphone
  • Contacts
  • Calendar
  • Location Services
  • Photos
  • Full Disk Access

7. Children's Privacy

Clarity Code is safe for users of all ages. Since we don't collect any data, there is no information collected from children or anyone else. Parents can be confident that their children's use of Clarity Code is completely private.

8. Your Rights

Since we don't collect any data about you:

  • Right to Access: There is no data to access
  • Right to Deletion: There is no data to delete
  • Right to Portability: There is no data to port
  • Right to Opt-Out: There is nothing to opt out of

You maintain complete control over all files you create or edit. You can delete them, move them, or manage them however you choose through macOS.

9. Data Security

While we don't collect data, we still take security seriously:

9.1 App Security

  • Code-signed with Apple Developer ID
  • Notarized by Apple for malware protection
  • Sandboxed to restrict app capabilities
  • Uses macOS security features (Hardened Runtime, etc.)

9.2 Your File Security

  • Files are subject to standard macOS file permissions
  • We recommend using FileVault for full-disk encryption
  • We recommend strong passwords for your Mac user account
  • Back up important files using Time Machine or other backup solutions

  • Posted on this page with an updated "Last Updated" date

  • Effective immediately upon posting (or as stated in the update)

Our commitment: We will never introduce data collection without clear notice and your explicit consent. Privacy is a core feature, not an afterthought.
