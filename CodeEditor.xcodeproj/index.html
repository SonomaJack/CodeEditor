Frequently Asked Questions

Is this a subscription or one-time purchase?

Clarity Code Premium is a one-time purchase. Pay once and own it forever across all your Macs. No recurring fees, no subscription.

What can I do with the free version?

The free version includes full support for Markdown, JSON, XML, CSV, and plain text editing. You can save, open, and print documents without any limitations.

Which programming languages are supported?

Premium unlocks syntax highlighting and code completion for Swift, Python, JavaScript, TypeScript, Java, C#, C, C++, Go, Rust, Ruby, PHP, SQL, HTML, CSS, Salesforce Apex, and more.

Does it work offline?

Yes! Clarity Code works completely offline. Your code never leaves your Mac, and there's no internet connection required.

What macOS version do I need?

Clarity Code requires macOS 13.0 (Ventura) or later. It's optimized for both Intel and Apple Silicon Macs.

Can I use this for Salesforce development?

Absolutely! Clarity Code has first-class support for Salesforce Apex, including .cls and .trigger files, SOQL syntax highlighting, and Apex-specific code completion.

Is there a trial period for Premium features?

You can use the free version to get a feel for the app. Premium features can be unlocked with an in-app purchase at any time.

Do you collect my code or data?

Never. Clarity Code has zero telemetry, zero analytics, and zero data collection. Your code stays on your Mac, period.
