# Clarity Code Edit - User Guide

## Quick Start

### Creating Your First File
1. Press **⌘N** or click the **+** button in the sidebar
2. Enter a filename (optional)
3. Select your language or enable auto-detection
4. Click **Create** and start coding!

### Opening Files
- Press **⌘O** or click the folder icon
- Navigate to your code file
- Supported: Swift, Python, JavaScript, Java, Apex, C++, and 15+ more languages

## File Management

### Saving Files
- **⌘S** - Save current file
- **⇧⌘S** - Save As (choose new location/name)
- **Orange dot** - Indicates unsaved changes
- **Auto-save** - Enable in Settings (⌘,)

### Multiple Files
- Open multiple files - they appear as sidebar tabs
- Click any tab to switch files
- Right-click for file operations (Save, Save As, Show in Finder, Close)
- Modified files show an orange indicator

### Recent Files
Access recently opened files from **File → Open Recent** menu

## Editing Features

### Text Editing
- Native macOS text editing with syntax highlighting
- Line numbers (toggle with toolbar button)
- Monospaced font optimized for code
- Full undo/redo support (⌘Z, ⇧⌘Z)
- Horizontal and vertical scrolling

### Zoom & Font Size
- **⌘+** - Zoom In
- **⌘-** - Zoom Out
- **⌘0** - Reset Zoom
- Current size shown in toolbar (e.g., "13pt")
- Range: 8pt to 24pt

### Navigation
- **⌘L** - Go to Line (jump to specific line number)
- Line and column position shown in status bar
- Cursor position updates in real-time

## Find & Search

### Basic Find
- **⌘F** - Open Find panel
- **⌘G** - Find Next
- **⇧⌘G** - Find Previous

### Find Options
- Case Sensitive
- Whole Words Only
- Regular Expressions

### Find and Replace (Premium)
- **⌥⌘H** - Open Find and Replace
- Replace one match or all at once
- Column-restricted search available
- Full regex support

### Multi-File Search (Premium)
- **⇧⌘F** - Search across all open files
- Click results to jump to location
- Find function definitions, variables, patterns

## Troubleshooting

### File Won't Open
- Check file encoding (editor supports UTF-8, ASCII, ISO-8859-1)
- Binary files cannot be opened as text
- Try opening with different app if encoding is unsupported

### Syntax Highlighting Not Working
- Check language selection in toolbar
- Enable auto-detection for automatic language detection
- Some languages require premium upgrade

### Can't Save File
- Check file permissions
- Ensure destination folder exists
- Try Save As to choose new location

### Settings Not Saving
- Settings are stored in UserDefaults
- Some settings apply to new files only
- Reopen files for some settings to take effect
